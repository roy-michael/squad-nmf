✅ NEW CLI COMMAND: temporal-cluster

   Discovers multiple sound patterns WITHIN audio files
   
   Usage:
   ------
   python -m src temporal-cluster --input-dir ./recordings --n-patterns 2
   
   Features:
   • Time-stamped pattern discovery (start/end times in seconds)
   • Active component tracking (which NMF bases are dominant)
   • Pattern strength metric (0-1 scale: 0=background, 1=strong)
   • Parallel processing support (joblib with all cores by default)
   • JSON export for programmatic integration
   • Comprehensive user interpretation guide
   
   Parameters:
   • --input-dir: WAV directory (required)
   • --n-patterns: Temporal clusters per file (default: 3)
   • --output-json: Results file path (default: temporal_analysis.json)
   • --n-jobs: Parallel workers (default: -1 for all cores)
   • --verbose: Debug logging

✅ HOW IT WORKS

   Problem Solved:
   • Traditional clustering assigns each FILE to one cluster
   • Real recordings contain MULTIPLE patterns (vehicles, noise)
   • This feature discovers patterns WITHIN files
   
   Solution:
   1. Extract NMF decomposition (W basis, H activations)
   2. Cluster time frames of H matrix (not entire file)
   3. Group similar moments → temporal patterns
   4. Map frame indices to time ranges
   5. Report components and strength per pattern

   Example:
   30-second recording with:
   • 0-10s: Background ocean noise
   • 10-20s: Ship propulsion
   • 20-30s: Different vehicle sound
   
   Result:
   Pattern_0: 0-30s (background, strength 0.001)
   Pattern_1: 10-20s (vehicle 1, strength 0.15)
   Pattern_2: 20-30s (vehicle 2, strength 0.12)

✅ ANSWERING USER QUESTIONS

   Q: "How can I identify how the clustering was done?"
   A: Each pattern shows:
      • Exact time range (start and end seconds)
      • Active NMF components (which bases dominate)
      • Strength metric (0-1 scale)
      • JSON export for detailed analysis
   
   Q: "I expect most files to contain several clusters"
   A: Temporal clustering discovers multiple patterns within
      individual files by clustering NMF activation matrices.
      • Default: 2-3 patterns per file
      • Customizable: --n-patterns parameter
      • Results show time ranges for each pattern
