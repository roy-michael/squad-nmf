THE THREE VISUALIZATIONS EXPLAINED

1. TIMELINE PLOT
────────────────
Three Panels:
  Panel 1: Stacked area (all components colored)
  Panel 2: Individual lines (one line per component)
  Panel 3: Cluster assignments (color bands showing patterns)

What It Shows:
  • When each component is active
  • Which components activate together (OVERLAPPING LINES = SIMULTANEOUS)
  • Which pattern each time frame belongs to

Quick Read:
  • Spike in Panel 2 = acoustic event
  • Multiple lines overlapping at spike = multiple components
  • Multiple components at same time = multiple sources or complex signal


2. HEATMAP
──────────
Grid: Components (rows) vs Time (columns)
Color: Red (high activation) to Black (no activation)

What It Shows:
  • Each pixel = one component at one time
  • RED pixel = component actively contributing
  • BLACK pixel = component inactive
  • Vertical red lines = moments when components activate
  • Cyan dashed lines = cluster boundaries

Quick Read:
  • Multiple RED PIXELS IN SAME COLUMN = SAME TIME = SIMULTANEOUS
  • Narrow red line = brief event
  • Wide red stripe = sustained signal
  • Different row positions = different components


3. SUMMARY CHART
────────────────
Bar Chart: One chart per pattern
  • X-axis: Component 0-5
  • Y-axis: Mean activation in that pattern
  • Red borders: Significant components (>0.05)

What It Shows:
  • Which components define each pattern
  • How strong each component is (bar height)
  • Comparison between patterns

Quick Read:
  • Red-bordered bar = important component
  • Taller bar = stronger component
  • Multiple red borders in same pattern = complex signal
  • Different red borders between patterns = different sources

DETECTING SIMULTANEOUS SOURCES

Checklist - If you see these, sources are simultaneous:

Timeline:
  ✓ Multiple component lines overlap at peak
  ✓ Lines spike at exact same time frame
  ✓ No time delay between peaks

Heatmap:
  ✓ Multiple RED pixels in SAME COLUMN
  ✓ Vertical red lines at SAME X coordinate
  ✓ No staggered red patterns

Summary:
  ✓ Multiple red-bordered bars in SAME PATTERN chart
  ✓ High bar heights for multiple components
  ✓ Components appear together (not in different patterns)

═══════════════════════════════════════════════════════════════════════════

MATHEMATICAL PROOF

NMF H matrix: Components × Time frames

H[i,t] = activation of component i at time t

Single source at time t:
  H[0,t] = 0.20  ← one component high
  H[1,t] = 0.01  ← others low
  H[2,t] = 0.00
  ...

Result: One vertical line in heatmap

Multiple simultaneous sources at time t:
  H[0,t] = 0.15  ← component 0 high
  H[1,t] = 0.12  ← component 1 ALSO high (same t!)
  H[2,t] = 0.08  ← component 2 high
  ...

Result: Multiple vertical lines in heatmap AT SAME TIME

Why? NMF decomposes spectrogram as:
  Spectrogram[t] = sum(W[:,i] * H[i,t] for all i)

When multiple H[i,t] high at same t, multiple W bases contribute.
Multiple bases = complex signal = multiple sources needed.
