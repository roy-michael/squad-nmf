🏗️ ARCHITECTURE

  Input Layer (AudioLoader):
  • Load WAV files (any SR, mono/stereo)
  • Validate file format and integrity
  • Convert stereo to mono if needed
  → Output: Audio array + sample rate

  Preprocessing Layer (AudioPreprocessor):
  • STFT (Spectral decomposition)
  • Spectral gating (noise reduction)
  • HPSS (Harmonic-Percussive separation)
  • Mel-scale transformation
  → Output: Denoised Mel spectrogram (512 bins)

  Feature Extraction Layer (NMFFeatureExtractor):
  • NMF decomposition (6 components)
  • Extract basis functions (W matrix)
  • Extract activations (H matrix)
  • Compute statistical moments (8 per matrix)
  • Normalize to [0,1] range
  → Output: 48-dimensional feature vector

  Classification Layer (SoundClassifier):
  • RandomForest / SVM / GradientBoosting
  • Train on feature vectors
  • Predict class label
  • Estimate class probabilities
  → Output: Predicted class + confidence
